# DailyAmount image uploads

Upload the images into this folder using these exact filenames:

- `sidebar-finance.png` — sidebar financial illustration
- `cash-illustration.png` — cash section illustration
- `bank-illustration.png` — bank section illustration
- `aeps-illustration.png` — AEPS section illustration
- `reconciliation-illustration.png` — reconciliation panel illustration
- `balance-overview.png` — balance overview artwork

These files are served from `/assets/reconciliation/<filename>`. Keep the filenames and `.png` extensions unchanged so the existing `/dailyamount` page can load them.
