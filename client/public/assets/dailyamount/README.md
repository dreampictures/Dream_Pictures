# DailyAmount image assets

Drop the supplied PNGs in this folder using these exact names. The page uses
Lucide icons as fallbacks until an image is present.

| File | Placement |
| --- | --- |
| `sidebar-finance.png` | Cover image behind the full left navigation card |
| `opening-balance.png` | Opening Balance summary icon |
| `cash-total.png` | Cash Total summary icon |
| `bank-total.png` | Bank Total summary icon |
| `aeps-wallet.png` | AEPS Wallet summary icon |
| `difference.png` | Difference summary icon |
| `cash-illustration.png` | Cash Counting total panel |
| `bank-illustration.png` | Bank Balances heading |
| `aeps-illustration.png` | AEPS Wallet heading |

Square transparent PNGs work best for the summary icons. The left navigation
image is cropped to fill the whole sidebar, so a tall portrait image is best.
