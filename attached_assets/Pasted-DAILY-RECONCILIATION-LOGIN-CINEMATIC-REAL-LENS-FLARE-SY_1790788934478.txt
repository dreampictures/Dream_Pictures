2. MOST IMPORTANT — NO JERKY MOVEMENT
==================================================

The previous animation had a major problem:

The flare was moving in visible steps and stopping between positions.

FIX THIS COMPLETELY.

The flare movement MUST be:

- continuous
- perfectly smooth
- frame-independent
- cinematic
- fluid
- natural

NEVER animate the flare using a sequence of discrete
left/top position jumps.

DO NOT use:

left: 10%;

left: 30%;
left: 40%;

DO NOT use many CSS keyframes with sudden position changes.

Instead use a smooth continuous animation system.

Prefer:

requestAnimationFrame()

combined with:

- elapsed time
- normalized progress
- smooth interpolation
- transform: translate3d()
- opacity
- scale
- blur

The animation must remain smooth even if the frame rate changes.

==================================================
4. REAL CAMERA OPTICAL EFFECT
==================================================

Do NOT create one large glowing circle.

A real lens flare should consist of MULTIPLE optical components.

Build the flare from several layered elements.

A. PRIMARY LIGHT SOURCE

A small extremely bright warm-white/golden core.

It should be:

- sharp in the center
- extremely bright
- surrounded by soft golden bloom

The core should NOT look like a simple yellow circle.

Use layered radial gradients and blur.

--------------------------------------------------

B. ANAMORPHIC HORIZONTAL STREAK

Add a very thin horizontal cinematic light streak.

Characteristics:

- extremely bright near the source
- fades smoothly toward both sides
- warm gold/white center
- very subtle blue/cyan edge contamination
- soft Gaussian-like blur

The streak should stretch horizontally as the flare
moves through the scene.

--------------------------------------------------

C. LENS GHOSTS

Add subtle translucent lens ghosts.

Use approximately 4–7 ghost elements.

They should:

- appear at different distances from the primary light
- have different sizes
- have very low opacity
- move with optical relationship to the main flare
- fade in/out naturally

DO NOT make them look like obvious circles.

They should be subtle enough that the viewer may not
immediately notice them.

--------------------------------------------------

D. LENS RINGS

Add 1–3 extremely subtle translucent rings.

They should be:

- soft
- partially transparent
- slightly blurred
- warm/cool mixed
- never solid circles

They should react naturally as the light crosses the screen.

--------------------------------------------------

E. BLOOM

The primary flare should have a soft bloom.

Use multiple layers:

small bright core
+
medium warm glow
+
large extremely soft glow

The outer glow should be subtle.

DO NOT make the entire login screen glow yellow.

==================================================
5. PHYSICS-LIKE LIGHT BEHAVIOUR
==================================================

The brightness must change naturally according to the
flare's position.

Use a smooth brightness curve.

For example:

APPROACH:

CENTER / PEAK:

EXIT:
gradually decreasing intensity

Do NOT use sudden opacity changes.

Use smooth interpolation such as:

easeInOut
or another continuous easing function.

==================================================
6. FLARE SHOULD NOT MOVE AT CONSTANT SPEED
==================================================

A real cinematic camera movement should have subtle
acceleration/deceleration.

Use:

slow start
→ gradual acceleration
→ smooth cruising movement
→ gentle deceleration
→ exit

But IMPORTANT:

There must be NO visible stopping.

The light should always remain in continuous motion.
